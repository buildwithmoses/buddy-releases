# Buddy — Downloads

Latest release for macOS:

**[Download Buddy](https://github.com/buildwithmoses/buddy-releases/releases/latest/download/Buddy.dmg)**

Requires macOS. Buddy asks for Accessibility, Screen Recording, and Microphone
permission on first launch — it needs them to see your screen and hear you.

Installed copies update themselves via Sparkle using `appcast.xml` in this repo.

Source lives in a private repo; this one only holds the built app.
